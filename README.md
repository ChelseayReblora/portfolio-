# Chelseay Anne D. Reblora | Portfolio

Personal portfolio of a Computer Engineering graduate (Cybersecurity) from Mapúa University, showcasing work across cybersecurity, AI and software development.

**Live site:** https://chelseayreblora.github.io/portfolio-/

## Highlights
- Undergraduate thesis (first author): *Common Back Muscle Exercises in Gyms: Form Detection Using Optical Flow and Gated Recurrent Unit Networks*
- Eight Cisco NetAcad certifications (CCNA, CyberOps Associate, Ethical Hacker, Endpoint Security, IT Essentials and more) and an NVIDIA Deep Learning certification
- Best Presenter Award, 8th International Conference on Video, Signal and Image Processing
- Hands-on with Linux, Bash scripting and Cisco network configuration

## Tech stack
React · Vite · Framer Motion · CSS, deployed with GitHub Pages and GitHub Actions

## Features
- Dark blueprint-grid design with glassmorphism cards and red accents
- Animated typing effect and scroll-reveal sections built with Framer Motion
- Responsive layout, with reduced-motion support for accessibility
